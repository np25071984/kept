Kept web UI: mockups

Every page, locked before implementation (VISION.md §4.C).

Static HTML with the app's own palette, light and dark. Sample data is the Smiths from VISION.md: Sam (owner) and Jo; the Hyundai and the Kia; Zoe and Maya; Rex. Each page has design notes for what a picture can't show.

Icons are Lucide (ISC licence), inline. An icon replaces a word only for actions everyone recognises: the bell, search, menus, close and remove (×), edit (pencil), delete (bin), add (+), pause and resume, and the recurring mark. A row's actions are all icons or all words, never mixed. Primary actions, answers and anything with consequences or an unusual meaning keep their words: Save, Yes, merge, Revoke, Stop watching, Make it recurring. Every icon-only button has an aria-label and a tooltip.

Every page header has a language menu: a globe and the current code (EN, RU), opening English, Русский and "Browser default". It is a POST to /language, signed in or not: signed in, it is saved to the account; signed out, to a cookie holding only the language.
