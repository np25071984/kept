Design notes

  • Replaces the create-household command for new users.
  • An email that already has an account gets "You already have a household: sign in instead" after the code, not before, so the email step reveals nothing.
  • Starting categories are the fixed seed (VISION.md §3.6); the assistant's first conversation does the rest of setup, so this form stays four fields.
  • Abuse limit: codes per email and per IP per hour, as for sign-in.
