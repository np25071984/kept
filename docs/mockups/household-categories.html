Design notes

  • "Add subcategory" on a row opens an inline field under it, so nobody types paths like Car/Parking; the row shows where it will go.
  • "Add category" at the top adds a top-level one the same way.
  • Third-level rows have no "Add subcategory": three levels is the limit.
  • Rename edits the name in place; moving under another parent is a "Move to…" choice in the same editor.
  • A delete that something still uses is refused in place, naming what uses it.
