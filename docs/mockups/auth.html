Design notes

  • Time zone is a search picker, as in holdmytrack: zones grouped by region and sorted by today's GMT offset, west to east, labelled "(GMT−04:00) New York". Typing filters by place, region or IANA id, ignoring case and accents ("sao" finds São Paulo); ↑/↓ and Enter pick, Escape closes. Prefilled from the browser. "It's 2:14 PM there" follows the zone picked, so a wrong choice shows at once.
  • One way in: the web app and every assistant start here. A signed-out visit to the web app comes straight to this page, with no page of its own in front (VISION.md §3.6, "One way in").
  • The web app's version has no Cancel: there is nothing to go back to. Back leaves the site.
  • Every sign-in asks for a code (prompt=login), so signing out on a shared computer holds; codes are rate-limited per email and per address.
  • Already built; these are the current pages, kept as the reference look.
  • The web app skips consent; assistants see it once per connection.
  • Every email gets a code now; an email with no account and no invite continues to "After the code".
  • The code page says "We sent a code to jo@example.com" for every email, so the pages never reveal who has an account.
