Design notes

  • Opened from the bell; its badge counts unanswered questions, so a number always means "something needs you".
  • Only questions with an answer: possible duplicates, a cap passed, a recurring charge missing from a statement, an API key unused for a year. Recurring purchases logged on their date are news, not questions: the assistant mentions them in chat, and the purchase is marked in My purchases.
  • Merging keeps the purchase logged first and adds the later one's sources to it.
  • The assistant asks at most one per conversation, after the user's request is done (VISION.md §4.B).
