# Security

Report a vulnerability privately to [support@kept-ledger.com](mailto:support@kept-ledger.com) or through GitHub's "Report a vulnerability" button on this repository, never in a public issue. Include the steps to reproduce it and what an attacker gains.

You will get a reply within a week. Once a fix is deployed to kept-ledger.com, the report can be made public, with credit if you want it.

The security design (household isolation, row-level security, OAuth2) is in `docs/IMPLEMENTATION.md` §4 and §5.4.
