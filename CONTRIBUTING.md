# Contributing

Issues and pull requests are welcome. For anything bigger than a fix, open an issue first so the design can be agreed before the code is written.

## How changes are made

- Read `AGENTS.md`: the product boundaries, the documentation rules and the code conventions apply to people too.
- Work on a branch and open a pull request against `main`. A change that alters what a document in `docs/` specifies updates that document in the same pull request.
- `npm run typecheck` and `npm test` pass (`docs/DEVELOPMENT.md` has the setup).
